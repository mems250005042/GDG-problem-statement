# Apple-News
News related to stock prices of Apple , to use for LLM model

This Repository contains 3 tasks of Problem Statement one :
PS 1 :
Task 1: 7 days Forecast of Apple stock price and volatility using Time Series Model .


Task 2: A RAG and llm, Which answers the question related to the Apple and it's Stock prices on basis of last few years news about apple.


Task 3: Fetching a Live data of stock prices of Apple using websocket and trained a model on the backfill data but failed to predict the live data.
